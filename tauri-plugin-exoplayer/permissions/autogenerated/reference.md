## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-ping`
- `allow-loadVideo`
- `allow-playPause`
- `allow-setPaused`
- `allow-seek`
- `allow-seekTo`
- `allow-seekToPercentage`
- `allow-setVolume`
- `allow-addVolume`
- `allow-toggleMute`
- `allow-setResizeMode`
- `allow-stop`
- `allow-setSubVisibility`
- `allow-captureFrame`
- `allow-setAudioTrack`
- `allow-setSubtitleTrack`
- `allow-addSubtitle`
